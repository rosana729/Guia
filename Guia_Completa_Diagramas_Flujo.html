Conceptos

¿Qué son los Diagramas de Flujo?

Un diagrama de flujo es una representación gráfica de un algoritmo o proceso. Utiliza símbolos estandarizados conectados por flechas para mostrar el flujo de ejecución de las operaciones.

¿Para qué sirven?

  • ✅ Visualizar la lógica de un programa antes de programarlo
  • ✅ Comunicar ideas de manera clara y universal
  • ✅ Detectar errores lógicos en el diseño
  • ✅ Documentar procesos y algoritmos
  • ✅ Aprender a pensar de forma algorítmica

Reglas Básicas

1. Dirección del Flujo

El flujo general es de arriba hacia abajo y de izquierda a derecha

2. Inicio y Fin

Todo diagrama debe tener un inicio y un fin claramente definidos

3. Claridad

Cada símbolo debe contener información clara y concisa

4. Conexiones

Las flechas indican la secuencia de ejecución

Simbología de Diagramas de Flujo

Cada símbolo tiene un significado específico y se usa para representar diferentes tipos de operaciones:

⬭

INICIO / FIN

Uso: Marca el punto de inicio y finalización del algoritmo. Todo diagrama debe tener exactamente un inicio y uno o más puntos de fin.
Ejemplo:
INICIO
FIN
▱

ENTRADA / SALIDA

Uso: Representa operaciones de lectura de datos (entrada) o mostrar resultados (salida). El paralelogramo se inclina hacia la derecha.
Ejemplos:
Leer nombre
Mostrar total
Pedir edad
▭

PROCESO

Uso: Representa cualquier operación de procesamiento: cálculos, asignaciones, operaciones matemáticas.
Ejemplos:
Total = A + B
Contador = Contador + 1
Promedio = Suma / 3
◇

DECISIÓN

Uso: Representa una pregunta o condición que divide el flujo en dos o más caminos. Siempre tiene al menos dos salidas: SÍ (verdadero) y NO (falso).
Ejemplos:
¿X > 0?
¿A == B?
¿Hay copias?
→

FLECHAS

Uso: Conectan los símbolos e indican la dirección del flujo de ejecución. Las flechas muestran el orden en que se ejecutan las operaciones.
Uso:
Indican dirección
Conectan símbolos
Muestran secuencia
⭕

CONECTOR

Uso: Se usa cuando el diagrama es muy grande y necesita continuar en otra parte de la página. Los conectores con la misma letra se unen.
Ejemplo:
A → conecta con → A
B → conecta con → B

Diagramas de Flujo: Estructura y Ejemplos

🎯 En esta sección: Veremos cómo se compone un diagrama de flujo completo, su estructura, y practicaremos con varios ejemplos.

Composición de un Diagrama de Flujo

Un diagrama de flujo completo debe tener los siguientes elementos:

  1. Punto de INICIO - Marca donde comienza el algoritmo
  2. Entrada de datos - Solicita información al usuario
  3. Procesos - Realiza cálculos y operaciones
  4. Decisiones - Evalúa condiciones y toma caminos diferentes
  5. Salida de datos - Muestra resultados
  6. Punto de FIN - Marca donde termina el algoritmo

Estructura Básica

[INICIO] | v [Entrada de datos] | v [Proceso] | v ¿Decisión? ---SÍ---> [Proceso A] | | NO | v | [Proceso B] <-------------- | v [Salida de datos] | v [FIN]

📝 Actividad 1: Mayor de Dos Números

Problema: Leer dos números (A y B) y determinar cuál es el mayor.

[INICIO] | v [Leer A, B] | v ¿A > B? ---SÍ---> [Mostrar "A es mayor"] | | NO | v | [Mostrar "B es mayor"] <--------- | v [FIN]
💭 Pregunta: Si A = 5 y B = 3, ¿qué mostrará el algoritmo?

📝 Actividad 2: Número Par o Impar

Problema: Determinar si un número es par o impar.

[INICIO] | v [Leer N] | v ¿N mod 2 == 0? ---SÍ---> [Mostrar "Es PAR"] | | NO | v | [Mostrar "Es IMPAR"] <-------------- | v [FIN]
💭 Preguntas:
  • ¿Qué significa "mod"?
  • Si N = 7, ¿qué mostrará?

📝 Actividad 3: Calcular Factorial

Problema: Calcular el factorial de un número N (N! = 1 × 2 × 3 × ... × N)

[INICIO] | v [Leer N] | v [Factorial = 1] [i = 1] | v ¿i ≤ N? ---NO---> [Mostrar Factorial] | | SÍ | v | [Factorial = Factorial × i] | [i = i + 1] | | | v | (volver arriba) ----------- | v [FIN]
💭 Pregunta: Si N = 5, ¿cuál será el resultado? ¿Cuántas veces se repite el ciclo?

📝 Actividad 4: Promedio de Tres Números

Problema: Calcular el promedio de tres números.

[INICIO] | v [Leer A, B, C] | v [Suma = A + B + C] | v [Promedio = Suma / 3] | v [Mostrar Promedio] | v [FIN]

✅ Respuestas de las Actividades

Respuesta Actividad 1: Mayor de Dos Números

Si A = 5 y B = 3:

  • El algoritmo pregunta: ¿5 > 3?
  • La respuesta es SÍ (verdadero)
  • Por lo tanto, muestra: "A es mayor"

Si A = 2 y B = 8:

  • El algoritmo pregunta: ¿2 > 8?
  • La respuesta es NO (falso)
  • Por lo tanto, muestra: "B es mayor"

Respuesta Actividad 2: Número Par o Impar

¿Qué significa "mod"?

El operador "mod" (módulo) calcula el residuo de una división. Por ejemplo:

  • 7 mod 2 = 1 (porque 7 ÷ 2 = 3 con residuo 1)
  • 8 mod 2 = 0 (porque 8 ÷ 2 = 4 con residuo 0)

Si N = 7:

  • Calculamos: 7 mod 2 = 1
  • Preguntamos: ¿1 == 0? NO
  • Por lo tanto, muestra: "Es IMPAR"

Regla: Si el residuo es 0, el número es PAR. Si el residuo es 1, es IMPAR.

Respuesta Actividad 3: Calcular Factorial

Si N = 5, el factorial es 5! = 1 × 2 × 3 × 4 × 5 = 120

Paso a paso:

  1. Factorial = 1, i = 1 → ¿1 ≤ 5? SÍ → Factorial = 1 × 1 = 1, i = 2
  2. Factorial = 1, i = 2 → ¿2 ≤ 5? SÍ → Factorial = 1 × 2 = 2, i = 3
  3. Factorial = 2, i = 3 → ¿3 ≤ 5? SÍ → Factorial = 2 × 3 = 6, i = 4
  4. Factorial = 6, i = 4 → ¿4 ≤ 5? SÍ → Factorial = 6 × 4 = 24, i = 5
  5. Factorial = 24, i = 5 → ¿5 ≤ 5? SÍ → Factorial = 24 × 5 = 120, i = 6
  6. Factorial = 120, i = 6 → ¿6 ≤ 5? NO → Mostrar 120

El ciclo se repite 5 veces.

Respuesta Actividad 4: Promedio

Ejemplo con A=10, B=8, C=9:

  • Suma = 10 + 8 + 9 = 27
  • Promedio = 27 / 3 = 9
  • Muestra: 9

Comparación: Diagrama ↔ Pseudocódigo ↔ Código

🎯 Concepto Clave: El MISMO problema se puede expresar en diferentes formas, pero la LÓGICA permanece IGUAL.

Las Tres Representaciones

1. Diagrama de Flujo

  • Visual: Usa símbolos gráficos
  • Ventaja: Fácil de entender el flujo
  • Ideal para: Planificar y comunicar

2. Pseudocódigo

  • Lógico: Lenguaje natural estructurado
  • Ventaja: Independiente del lenguaje
  • Ideal para: Diseñar algoritmos

3. Código Real

  • Ejecutable: Funciona en la computadora
  • Ventaja: Implementa la solución
  • Ideal para: Crear programas reales

Ejemplo 1: Suma de Dos Números

Diagrama de Flujo
[INICIO] | v [Leer A] | v [Leer B] | v [Suma = A + B] | v [Mostrar Suma] | v [FIN]
Pseudocódigo
INICIO Leer A Leer B Suma ← A + B Mostrar Suma FIN
Python
a = float(input('Ingrese A: ')) b = float(input('Ingrese B: ')) suma = a + b print(f'La suma es: {suma}')
JavaScript
let a = parseFloat(prompt('Ingrese A:')); let b = parseFloat(prompt('Ingrese B:')); let suma = a + b; console.log('La suma es: ' + suma);
PHP
<?php $a = readline('Ingrese A: '); $b = readline('Ingrese B: '); $suma = $a + $b; echo "La suma es: $suma\n"; ?>

Ejemplo 2: Número Par o Impar

Diagrama de Flujo
[INICIO] | v [Leer N] | v ¿N mod 2 == 0? ---SÍ---> [Mostrar "Es PAR"] | | NO | v | [Mostrar "Es IMPAR"] <-------------- | v [FIN]
Pseudocódigo
INICIO Leer N SI (N mod 2 == 0) ENTONCES Mostrar "Es PAR" SINO Mostrar "Es IMPAR" FIN SI FIN
Python
n = int(input('Ingrese número: ')) if n % 2 == 0: print('Es PAR') else: print('Es IMPAR')
JavaScript
let n = parseInt(prompt('Ingrese número:')); if (n % 2 === 0) { console.log('Es PAR'); } else { console.log('Es IMPAR'); }
PHP
<?php $n = intval(readline('Ingrese número: ')); if ($n % 2 == 0) { echo "Es PAR\n"; } else { echo "Es IMPAR\n"; } ?>

Ejemplo 3: Calcular Factorial

Diagrama de Flujo
[INICIO] | v [Leer N] | v [Factorial = 1] [i = 1] | v ¿i ≤ N? ---NO---> [Mostrar Factorial] --> [FIN] | SÍ v [Factorial = Factorial × i] [i = i + 1] | v (volver arriba)
Pseudocódigo
INICIO Leer N Factorial ← 1 i ← 1 MIENTRAS (i ≤ N) HACER Factorial ← Factorial × i i ← i + 1 FIN MIENTRAS Mostrar Factorial FIN
Python
n = int(input('Ingrese N: ')) factorial = 1 for i in range(1, n + 1): factorial *= i print(f'Factorial: {factorial}')
JavaScript
let n = parseInt(prompt('Ingrese N:')); let factorial = 1; for (let i = 1; i <= n; i++) { factorial *= i; } console.log('Factorial: ' + factorial);
PHP
<?php $n = intval(readline('Ingrese N: ')); $factorial = 1; for ($i = 1; $i <= $n; $i++) { $factorial *= $i; } echo "Factorial: $factorial\n"; ?>

✅ Conclusión

¿Notas las similitudes?

  • ✓ La LÓGICA es exactamente la misma en los 4 lenguajes
  • ✓ Los PASOS son idénticos
  • ✓ Solo cambia la SINTAXIS (la forma de escribirlo)
  • ✓ Si entiendes el diagrama y el pseudocódigo, puedes programar en CUALQUIER lenguaje

Ejemplo 1: Registrar Libro

Problema: Agregar un nuevo libro verificando que no esté duplicado.

[INICIO] | v [Pedir código, titulo, autor, año, copias] | v ¿El código ya existe? ---SÍ---> [Mostrar error] | | NO | v | [Crear libro nuevo] | | | v | [Agregar a la lista] | | | v | [Mostrar "Registrado"] <---------------- | v [FIN]
Pseudocódigo
INICIO PEDIR codigo, titulo, autor, anio, copias SI el codigo ya existe ENTONCES MOSTRAR "Error: ese libro ya existe" SINO CREAR libro con esos datos AGREGAR libro a la lista MOSTRAR "Libro registrado" FIN SI FIN
Código Python
def registrar_libro(codigo, titulo, autor, anio, copias): # Verificar que el código no exista for libro in lista_libros: if libro["codigo"] == codigo: print("ERROR: Ya existe ese libro.") return # Crear el libro libro_nuevo = { "codigo": codigo, "titulo": titulo, "autor": autor, "anio": anio, "copias_totales": copias, "copias_disponibles": copias } # Agregar a la lista lista_libros.append(libro_nuevo) print(f"Libro '{titulo}' registrado.")

Ejemplo 2: Realizar Préstamo

Problema: Registrar un préstamo verificando libro, miembro y copias disponibles.

[INICIO] | v [Pedir código libro e ID miembro] | v ¿Libro existe? ---NO---> [Mostrar error] --> [FIN] | SÍ v ¿Miembro existe? ---NO---> [Mostrar error] --> [FIN] | SÍ v ¿Hay copias? ---NO---> [Mostrar error] --> [FIN] | SÍ v [Calcular fecha limite = hoy + 14 dias] | v [Crear registro de prestamo] | v [Copias disponibles = copias - 1] | v [Guardar prestamo en lista] | v [Mostrar confirmacion] | v [FIN]
Pseudocódigo
INICIO PEDIR codigo del libro PEDIR id del miembro SI el libro no existe ENTONCES MOSTRAR "Error: libro no encontrado" TERMINAR FIN SI SI el miembro no existe ENTONCES MOSTRAR "Error: miembro no encontrado" TERMINAR FIN SI SI copias disponibles = 0 ENTONCES MOSTRAR "Error: no hay copias" TERMINAR FIN SI CREAR prestamo (fecha hoy + 14 dias) RESTAR 1 a copias disponibles AGREGAR prestamo a la lista MOSTRAR "Préstamo realizado" FIN

def realizar_prestamo(codigo, id_miembro): from datetime import date, timedelta # Verificar libro libro = buscar_libro(codigo) if libro is None: print("ERROR: Libro no existe.") return # Verificar miembro miembro = buscar_miembro(id_miembro) if miembro is None: print("ERROR: Miembro no existe.") return # Verificar copias if libro["copias_disponibles"] == 0: print("ERROR: No hay copias.") return # Crear préstamo hoy = date.today() fecha_limite = hoy + timedelta(days=14) prestamo = { "id": generar_id(), "codigo": codigo, "id_miembro": id_miembro, "fecha_prestamo": str(hoy), "fecha_limite": str(fecha_limite), "devuelto": False } # Actualizar y guardar libro["copias_disponibles"] -= 1 lista_prestamos.append(prestamo) print("Préstamo realizado correctamente.")

Ejemplo 3: Buscar Libro

Problema: Buscar libros que contengan un término en título, autor o código.

[INICIO] | v [Pedir termino de busqueda] | v [Crear lista resultados vacia] | v [Tomar primer libro] | v ¿Termino en titulo, SÍ autor o codigo? -----------> [Agregar a resultados] | | NO | v <--------------------- ¿Quedan mas libros? --SÍ--> [Tomar siguiente] | NO v ¿Resultados vacios? --SÍ--> [Mostrar "Sin resultados"] | | NO | v v [Mostrar resultados] <------------ | v [FIN]
Pseudocódigo
INICIO PEDIR termino de busqueda CREAR lista_resultados vacia PARA CADA libro EN la lista HACER SI termino en titulo O autor O codigo ENTONCES AGREGAR libro a lista_resultados FIN SI FIN PARA SI lista_resultados vacia ENTONCES MOSTRAR "No se encontraron resultados" SINO MOSTRAR lista_resultados FIN SI FIN
Código Python
def buscar_libros(termino): termino = termino.lower() resultados = [] for libro in lista_libros: en_titulo = termino in libro["titulo"].lower() en_autor = termino in libro["autor"].lower() en_codigo = termino in libro["codigo"].lower() if en_titulo or en_autor or en_codigo: resultados.append(libro) return resultados def mostrar_resultados(resultados): if len(resultados) == 0: print("No se encontraron resultados.") else: print(f"Encontrados {len(resultados)} libro(s):") for libro in resultados: print(f" [{libro['codigo']}] {libro['titulo']}")

Conceptos Clave de Programación

📦

LISTA / ARREGLO

Una colección ordenada de elementos. Cada elemento tiene una posición (índice).
libros = ["Don Quijote", "1984"] libros[0] # "Don Quijote" libros[1] # "1984"
📋

DICCIONARIO

Una estructura con pares clave-valor. Como una ficha con campos etiquetados.
libro = { "codigo": "L001", "titulo": "El Principito", "copias": 3 } libro["titulo"] # acceder
⚙️

FUNCIÓN

Bloque de código reutilizable que realiza una tarea específica.
def saludar(nombre): print("Hola, " + nombre) saludar("Ana") # usar la función
🔀

CONDICIÓN (SI/SINO)

Permite tomar decisiones basadas en condiciones verdaderas o falsas.
if copias > 0: print("Disponible") else: print("No hay copias")
🔁

BUCLE (PARA CADA)

Repite una acción para cada elemento de una colección.
for libro in lista_libros: print(libro["titulo"]) # Imprime cada título
🔍

BÚSQUEDA

Encontrar elementos que cumplan una condición específica.
for libro in lista_libros: if libro["codigo"] == "L001": print("¡Encontrado!") break

💡 Conclusión Final

Aprender a programar es aprender a PENSAR de forma lógica y estructurada.

  • ✅ Los diagramas de flujo te ayudan a visualizar la lógica ANTES de programar
  • ✅ El pseudocódigo te permite diseñar sin preocuparte por la sintaxis
  • ✅ El código real (Python, JavaScript, PHP) implementa esa lógica
  • ✅ La lógica es UNIVERSAL - solo cambia la sintaxis del lenguaje
  • ✅ Si dominas los diagramas de flujo, puedes aprender CUALQUIER lenguaje de programación
